# Rock Paper Scissors 🎮

A browser-based Rock Paper Scissors game built with HTML, CSS, and JavaScript.

## Features

* Choose Rock, Paper, or Scissors.
* Play against a computer that selects randomly.
* Track your score and the computer's score.
* See whether each round is a win, loss, or draw.
* Enjoy a simple, interactive interface.

## Technologies Used

* HTML5
* CSS3
* JavaScript

## How to Run

1. Download or clone this repository.
2. Open `paper.html` in your browser.
3. Select Rock, Paper, or Scissors to play.

## What I Practised

* DOM manipulation and event listeners
* Functions and conditional logic
* Random number generation
* Updating the page dynamically
* Managing scores with JavaScript variables
